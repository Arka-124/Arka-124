## 🚀 Featured Projects

### 🚧 FogBot — Autonomous Mine-Safety Rover
*Smart India Hackathon 2026 — NMDC Problem Statement SIH26007*

An autonomous leading pilot rover and IoT command center that drives ahead of mine trucks to enable safe operation in dense fog and low-visibility open-cast iron ore mines.

* **Hardware:** Raspberry Pi 5, LiDAR, vision + 3D depth cameras, IR/ultrasonic sensors, GPS, STM32 motor controller.
* **Software:** Command dashboard and landing page with a Three.js/React digital-twin visualization of the rover (real-time risk states, hazard lighting).
* **Comms:** LoRaWAN as the backup communication channel.

### 📊 AI Data & Worker Performance Analytics
*Multi-module Streamlit dashboard for sales and workforce analytics*

A data science pipeline covering sales prediction, demand forecasting, worker performance analysis, an early-warning system, product recommendations, and sales trend analysis — built on trained scikit-learn models.

### 🚆 VM Website
*A high-performance, full-stack web application designed for complex data management.*

This project was built without relying on heavy frontend frameworks, demonstrating deep knowledge of **Vanilla JavaScript** and **DOM architecture**.

* **Architecture:** Built using **Class-based OOP** in JavaScript for modularity and scalability.
* **Performance:** Implemented efficient DOM manipulation (Map caching), passive scroll listeners, and requestAnimationFrame for buttery smooth 60fps animations.
* **Accessibility (A11y):** Fully compliant with ARIA standards, ensuring screen reader compatibility and keyboard navigation.
* **Backend:** RESTful API built with **Node.js, Express, and MongoDB** handling complex schemas and nested data structures.
* **Key Features:** Custom overlay navigation system, debounced search algorithms, and SVG turbulence filters.

### 🤖 Movie Review QA
*Built during Internship at IIT Kanpur*
A FastAPI backend that answers natural-language questions against a movie-review dataset using TF-IDF and cosine similarity matching.
* **Tech:** Python, FastAPI, scikit-learn.
* **Outcome:** Deployed API endpoint for querying reviews with relevance-ranked responses.
